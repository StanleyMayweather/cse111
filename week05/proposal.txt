CSE 111 Proposal for a Student Chosen Program

1. What is the title of your program? Sentinel Budget Manager 

2. What real-world problem will your program address or help to solve? Many individuals struggle to maintain a clear overview of their spending habits because data is often scattered across different platforms. This program provides a centralized tool to import transaction data from CSV files, categorize expenses automatically, and compare actual spending against a set budget limit to identify financial leaks.

3. What will you learn from developing this program? I will learn how to integrate complex Python concepts, specifically: Managing persistent data by reading from and potentially writing to external CSV files.Implementing robust error handling using try...except blocks to prevent crashes during file I/O or data conversion.Designing "pure" functions that are modular and easily testable with pytest.

4. What Python modules will your program use?  csv: To parse the expenses.csv file and handle tabular data.datetime: To timestamp reports and handle date-based filtering.pytest: To verify the mathematical and logic-based functions.os: To check for the existence of data files before attempting to open them.

5. List the names of functions you will need?  main(): The entry point that coordinates user input and output.load_transactions(filename): Opens the CSV file and returns a list of dictionaries representing transactions.calculate_category_totals(transactions): A logic function that iterates through data to sum spending by category.validate_currency(value): A helper function that ensures a string can safely be converted to a positive float.generate_status_report(totals, budget_limit): Compares totals to a limit and returns a string indicating if the user is over or under budget.

6. List the names of the test functions you will write. test_calculate_category_totals: Will use pytest to ensure that a sample list of transactions is aggregated into the correct sums for each category.test_validate_currency: Will verify that the function correctly identifies valid dollar amounts (like "10.50") while rejecting invalid strings (like "abc" or "-5.00").
